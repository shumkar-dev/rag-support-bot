RAG Telegram Bot

Телеграм-бот-консультант для бизнеса, собранный на n8n. Отвечает клиентам на вопросы о компании — цены, услуги, режим работы, условия — опираясь на загруженную базу знаний, а не на общие знания модели. Если ответа в базе нет, бот честно об этом говорит и передаёт вопрос администратору.

Стек: n8n, Google Gemini, Qdrant, Google Sheets, Telegram Bot API.

Как устроено

Проект состоит из двух workflow.

Загрузка базы знаний (rag_ingestion.json). Через веб-форму загружается PDF с информацией о компании. Из файла извлекается текст, разбивается на фрагменты по 1000 символов с перекрытием 200, каждый фрагмент преобразуется в вектор через Gemini и сохраняется в Qdrant. К фрагментам добавляются метаданные — имя исходного файла и дата загрузки.

Бот (rag_bot.json). Клиент пишет в Telegram, сообщение обрабатывает AI-агент на Gemini. Агент использует два инструмента: семантический поиск по Qdrant и запись клиента в Google Sheets. Найдя информацию в базе, агент отвечает по существу. Если данных нет — возвращает служебный маркер, клиент получает вежливый отказ, а администратору приходит уведомление с текстом вопроса.

Отдельная ветка работает по расписанию: раз в сутки проверяет таблицу клиентов и отправляет напоминание тем, кто не выходил на связь три дня и больше.

Ключевые технические решения

Даты формируются на стороне n8n через $now, а не запрашиваются у модели — LLM не имеет доступа к текущему времени.

Признак «нет ответа» передаётся через маркер в начале сообщения, а не определяется поиском фразы в тексте — модель может перефразировать ответ, и проверка перестанет срабатывать.

На нодах отправки включены retry и continue on error. Если клиент заблокировал бота, ошибка отправки не прерывает цепочку, и статус напоминания корректно записывается в таблицу.

Подключена память диалога — окно на 10 сообщений с ключом сессии по chat_id, что позволяет агенту вести последовательный разговор.

Установка

Импортировать оба workflow в n8n и подключить credentials: Google Gemini, Qdrant, Telegram, Google Sheets.

Заменить плейсхолдеры YOUR_GOOGLE_SHEET_ID и YOUR_ADMIN_CHAT_ID, указать имя коллекции Qdrant. Имя коллекции должно совпадать в обоих workflow.

Создать таблицу с колонками: chat_id, name, last_message, last_date, reminded. Формат даты YYYY-MM-DD, поле reminded принимает значения да/нет.
